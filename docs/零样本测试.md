# 零样本测试-迁移学习
## NDP迁移学习
脚本`src/train_transfer.py`来实现迁移学习功能，该脚本实现了迁移学习任务，使用train_2304601和train_468101作为训练集，然后在train_111801上进行测试。这是一个零样本迁移学习场景。

接下来，我们需要配置文件来 `configs/transfer.yaml` 指定迁移学习参数。

1. train_transfer.py - 实现迁移学习功能的新脚本，支持从多个数据集加载训练数据，并在单独的测试集上评估性能
2. transfer.yaml - 配置文件，指定训练集和测试集，以及骨干网络的配置参数等

脚本中实现了以下核心功能：
- 合并多个CSV数据集为一个训练集
- 支持从预训练模型加载权重（可选）
- 保存训练过程指标和最佳模型
- 生成训练和测试记录
- 在测试场景中可视化网格地图重建

可以通过以下命令运行迁移学习训练：

```bash
python -m src.train_transfer
```

运行后，脚本将：
1. 加载指定的(两个)训练数据集和(一个)测试数据集
2. 训练模型并记录性能指标
3. 将结果保存到`results/transfer`目录下，包括：
   - 最佳模型权重：`results/transfer/checkpoints/ndp_transfer_best.pt`
   - 性能指标曲线图：`results/transfer/metrics_curve.png`
   - 详细的迁移学习结果：`results/transfer/transfer_results.txt`

如果想修改训练参数或数据集路径，只需编辑`configs/transfer.yaml`文件即可。
另外，如果想从预训练模型开始训练，可以取消配置文件中`load_ckpt`参数的注释并指定预训练模型路径。

这个迁移学习实验将帮助评估模型在新场景中的泛化能力，是衡量模型鲁棒性的重要指标。

## 基线模型迁移学习
接下来对两个基线模型（线性回归和SVR）进行迁移学习实验，并与NDP模型进行对比。

1. **基线模型迁移学习脚本**：`src/baselines/baseline_transfer.py`
   - 这个脚本实现了与NDP模型类似的迁移学习功能，但针对线性回归和SVR两个基线模型
   - 它支持从多个数据集加载训练数据并在单独的测试集上评估性能
   - 可以自动加载NDP迁移学习结果并生成三种模型的性能对比图表

2. **基线模型迁移学习配置文件**：`configs/baseline_transfer.yaml`
   - 配置了相同的训练和测试数据集路径，确保与NDP模型的迁移学习实验保持一致
   - 指定了基线模型的参数设置
   - 配置了结果保存目录和可视化选项

可以使用以下命令运行这个脚本，执行基线模型的迁移学习实验并与NDP模型进行对比。
```bash
python -m src.baselines.baseline_transfer
```
