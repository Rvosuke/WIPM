# 零样本测试-迁移学习

迁移学习任务，使用train_111801和train_468101作为训练集，然后在train_2304601上进行测试。这是一个零样本迁移学习场景。

脚本`src/scripts/train_transfer.py`来实现迁移学习功能，该脚本实现了将 train_111801 和 train_468101 作为训练集，train_2304601 作为测试集的功能。

接下来，我们需要配置文件来 `configs/transfer.yaml` 指定迁移学习参数。

1. train_transfer.py - 实现迁移学习功能的新脚本，支持从多个数据集加载训练数据，并在单独的测试集上评估性能
2. transfer.yaml - 配置文件，指定使用train_111801和train_468101作为训练集，train_2304601作为测试集

脚本中实现了以下核心功能：
- 合并多个CSV数据集为一个训练集
- 支持从预训练模型加载权重（可选）
- 保存训练过程指标和最佳模型
- 生成详细的训练和测试分析报告

可以通过以下命令运行迁移学习训练：

```bash
python -m src.scripts.train_transfer --cfg configs/transfer.yaml
```

运行后，脚本将：
1. 加载指定的两个训练数据集和一个测试数据集
2. 训练模型并记录性能指标
3. 将结果保存到`results/transfer`目录下，包括：
   - 最佳模型权重：`results/transfer/checkpoints/ndp_transfer_best.pt`
   - 性能指标曲线图：`results/transfer/transfer_metrics_curve.png`
   - 详细的迁移学习结果：`results/transfer/transfer_results.txt`
   - TensorBoard日志：`results/transfer/runs/`

如果想修改训练参数或数据集路径，只需编辑`configs/transfer.yaml`文件即可。
另外，如果想从预训练模型开始训练，可以取消配置文件中`load_ckpt`参数的注释并指定预训练模型路径。

这个迁移学习实验将帮助评估模型在新场景（train_2304601）中的泛化能力，是衡量模型鲁棒性的重要指标。
