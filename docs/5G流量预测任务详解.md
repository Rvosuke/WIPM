# 5G流量预测任务详解

## 1. 任务概述

5G流量预测是一个时间序列预测任务，旨在根据历史流量数据预测未来的5G网络流量。我们使用神经扩散概率模型(NDP)进行时间序列建模，实现高精度的短期和长期流量预测。

### 1.1 数据集介绍

数据集包含多个5G基站的流量数据，每个文件代表一个独立的预测任务：

- **Number类数据**（数值型指标）：
  - `number_value_cell_2_beam_19.csv`：小区2波束19
  - `number_value_cell_2_beam_27.csv`：小区2波束27

- **Throughput (thp)类数据**（吞吐量指标）：
  - `thp_value_cell_0_beam_1.csv`：小区0波束1
  - `thp_value_cell_2_beam_0.csv`：小区2波束0

每个CSV文件包含以下字段：
- `date`：时间戳（yyyy/MM/dd HH:mm）
- `value`：原始数值
- `ma_value`：滑动窗口均值（窗口=5）
- `lg_ma_value`：ma_value的以10为底对数

### 1.2 预测任务

- **多样本训练**：训练集:测试集 = 8:2（80%训练，20%测试）
- **少样本训练**：训练集:测试集 = 2:8（20%训练，80%测试）
- **长期预测**：输入连续12小时数据，预测未来24小时数据
- **短期预测**：输入连续12小时数据，预测未来6小时数据

## 2. 技术实现

### 2.1 神经扩散概率模型(NDP)

我们的模型基于扩散概率模型，是一种生成模型，通过逐步去噪的过程从随机噪声生成目标数据。对于时间序列预测任务，我们使用条件扩散模型，将历史流量数据作为条件，预测未来流量。

#### 2.1.1 模型架构

```python
class NDPNoisePredictor(nn.Module):
    def __init__(self, in_dim: int, hidden: int = 128, n_layers: int = 6, heads: int = 4):
        super().__init__()
        # 输入特征投影
        self.x_proj = nn.Sequential(
            nn.Linear(in_dim, hidden),
            nn.GELU(),
            nn.Linear(hidden, hidden),
        )
        # 目标值投影
        self.y_proj = nn.Sequential(
            nn.Linear(1, hidden),
            nn.GELU(),
            nn.Linear(hidden, hidden),
        )
        # 扩散时间步嵌入
        self.time_embed = TimeEmbedding(hidden)
        self.time_dense = nn.Sequential(
            nn.Linear(hidden, hidden),
            nn.GELU(),
            nn.Linear(hidden, hidden),
        )
        # 双向注意力模块
        self.blocks = nn.ModuleList(
            [BiDimAttnBlock(hidden, heads) for _ in range(n_layers)]
        )
        self.post_norm = nn.LayerNorm(hidden)
        self.mlp = nn.Sequential(
            nn.GELU(), nn.Linear(hidden, hidden), nn.GELU(), nn.Linear(hidden, 1)
        )
```

模型核心是双向注意力模块，可以同时捕捉输入序列和输出序列之间的依赖关系：

```python
class BiDimAttnBlock(nn.Module):
    def __init__(self, hidden: int, num_heads: int = 4) -> None:
        super().__init__()
        self.norm1 = nn.LayerNorm(hidden)
        self.norm2 = nn.LayerNorm(hidden)
        self.mhsa_dim = nn.MultiheadAttention(hidden, num_heads, batch_first=True)
        self.mhsa_seq = nn.MultiheadAttention(hidden, num_heads, batch_first=True)
        self.ffn = nn.Sequential(
            nn.LayerNorm(hidden),
            nn.Linear(hidden, hidden * 4),
            nn.GELU(),
            nn.Linear(hidden * 4, hidden),
        )
```

#### 2.1.2 扩散过程

扩散模型包含两个过程：

1. **前向扩散**：逐步给目标数据添加噪声
2. **反向去噪**：从噪声数据中恢复原始数据

```python
class DiffusionSchedule:
    def __init__(self, timesteps=1000, beta_start=1e-4, beta_end=2e-2, device="cpu"):
        # 扩散计划设置
        self.T = timesteps
        self.betas = torch.linspace(beta_start, beta_end, timesteps, device=device)
        self.alphas = 1.0 - self.betas
        self.alpha_cumprod = torch.cumprod(self.alphas, dim=0)
        self.sqrt_alpha_cum = torch.sqrt(self.alpha_cumprod)
        self.sqrt_one_minus_alpha_cum = torch.sqrt(1 - self.alpha_cumprod)

    # 前向扩散采样
    def q_sample(self, y0: Tensor, t: Tensor, noise: Tensor) -> Tensor:
        a = self.sqrt_alpha_cum[t].unsqueeze(1)
        b = self.sqrt_one_minus_alpha_cum[t].unsqueeze(1)
        return a * y0 + b * noise

    # 预测前一步（去噪）
    def predict_prev(self, y_t: Tensor, eps_pred: Tensor, t: Tensor) -> Tensor:
        beta_t = self.betas[t].unsqueeze(1)
        alpha_t = self.alphas[t].unsqueeze(1)
        alpha_cum_t = self.alpha_cumprod[t].unsqueeze(1)
        sqrt_one_minus = self.sqrt_one_minus_alpha_cum[t].unsqueeze(1)

        coef1 = 1.0 / torch.sqrt(alpha_t)
        coef2 = beta_t / sqrt_one_minus
        return coef1 * (y_t - coef2 * eps_pred)
```

#### 2.2.2 数据集划分

```python
def train_test_split(data, dates, split_ratio=0.8, is_many_shot=True, random_seed=42):
    # 设置随机种子确保结果可复现
    np.random.seed(random_seed)

    # 获取数据总数
    n_samples = len(data)

    # 创建索引并随机打乱
    indices = np.arange(n_samples)
    np.random.shuffle(indices)

    # 根据是否为多样本训练确定训练集大小
    if is_many_shot:
        # 多样本训练: 80%训练，20%测试
        train_size = int(n_samples * split_ratio)
    else:
        # 少样本训练: 20%训练，80%测试
        train_size = int(n_samples * (1 - split_ratio))

    # 划分训练集和测试集索引
    train_indices = indices[:train_size]
    test_indices = indices[train_size:]

    # 根据索引获取相应的数据
    train_data = data[train_indices]
    test_data = data[test_indices]
    train_dates = dates[train_indices]
    test_dates = dates[test_indices]

    return train_data, test_data, train_dates, test_dates
```

#### 2.2.3 时间序列数据集构建

```python
class TimeSeriesDataset(Dataset):
    def __init__(self, data, input_window=12, pred_window=24, stride=1):
        self.data = data
        self.input_window = input_window
        self.pred_window = pred_window
        self.stride = stride
        self._prepare_sequences()

    def _prepare_sequences(self):
        """准备输入序列和目标序列"""
        self.samples = []
        total_len = len(self.data)

        for i in range(0, total_len - self.input_window - self.pred_window + 1, self.stride):
            x_seq = self.data[i:i+self.input_window]
            y_seq = self.data[i+self.input_window:i+self.input_window+self.pred_window, 0:1]
            self.samples.append((x_seq, y_seq))
```

#### 2.3.1 模型训练

```python
def train(model, train_loader, optimizer, device, epoch, writer=None):
    model.model.train()
    total_loss = 0

    for batch_idx, (x, y) in enumerate(train_loader):
        x, y = x.to(device), y.to(device)
        optimizer.zero_grad()

        # 计算整个序列的损失
        # x形状：[B, input_window, feature_dim]
        # y形状：[B, pred_window, 1]
        loss = model.loss(x, y)
        loss.backward()
        optimizer.step()

        total_loss += loss.item()

    avg_loss = total_loss / len(train_loader)
    if writer:
        writer.add_scalar('Loss/train', avg_loss, epoch)

    return avg_loss
```

## 3. 实验结果分析

### 3.1 预测性能

我们在多个5G流量数据集上进行了实验，比较了长短期预测以及多样本和少样本训练的效果：

- **长期预测**（24小时）在多样本训练下通常获得较好的性能
- **短期预测**（6小时）即使在少样本训练下也能获得合理的结果
- MSE和MAE指标均显示NDP模型相比传统方法有明显优势

### 3.2 鲁棒性分析

通过向测试数据添加不同水平的高斯噪声，我们测试了模型的鲁棒性：

- 当噪声水平较低时（0.01-0.03），模型性能降低不明显
- 随着噪声水平增加（0.03-0.05），MSE和MAE都有所上升，但模型仍然能够保持基本的预测能力
- 多样本训练的模型通常比少样本训练的模型表现出更强的噪声鲁棒性
