# 5G流量预测任务详解

## 1. 任务概述

5G流量预测是一个时间序列预测任务，旨在根据历史流量数据预测未来的5G网络流量。我们使用神经扩散概率模型(NDP)进行时间序列建模，实现高精度的短期和长期流量预测。

### 1.1 数据集介绍

数据集包含多个5G基站的流量数据，每个文件代表一个独立的预测任务：

- **Number类数据**（数值型指标）：
  - `number_value_cell_2_beam_19.csv`：小区2波束19
  - `number_value_cell_2_beam_27.csv`：小区2波束27

- **Throughput (thp)类数据**（吞吐量指标）：
  - `thp_value_cell_0_beam_1.csv`：小区0波束1
  - `thp_value_cell_2_beam_0.csv`：小区2波束0

每个CSV文件包含以下字段：
- `date`：时间戳（yyyy/MM/dd HH:mm）
- `value`：原始数值
- `ma_value`：滑动窗口均值（窗口=5）
- `lg_ma_value`：ma_value的以10为底对数

### 1.2 预测任务

- **多样本训练**：训练集:测试集 = 8:2（80%训练，20%测试）
- **少样本训练**：训练集:测试集 = 2:8（20%训练，80%测试）
- **长期预测**：输入连续12小时数据，预测未来24小时数据
- **短期预测**：输入连续12小时数据，预测未来6小时数据

## 2. 技术实现

### 2.1 神经扩散概率模型(NDP)

我们的模型基于扩散概率模型，是一种生成模型，通过逐步去噪的过程从随机噪声生成目标数据。对于时间序列预测任务，我们使用神经扩散模型，将历史流量数据作为条件，预测未来流量。

### 2.2 数据处理流程

#### 2.2.1 数据加载与预处理

直接加载指定的CSV文件，然后进行归一化（standardScale）

#### 2.2.2 数据集划分

按照比例划分数据集

#### 2.2.3 时间序列数据集构建

数据集中每个样本包含：
- 输入序列，shape为(36, 3)
- 输出序列，shape为(36, 1) # 长期预测，仅预测value列


## 3. 实验结果分析

### 3.1 预测性能

我们在多个5G流量数据集上进行了实验，比较了长短期预测以及多样本和少样本训练的效果：

- **长期预测**（36小时）在多样本训练下通常获得较好的性能
- **短期预测**（18小时）即使在少样本训练下也能获得合理的结果
- MSE和MAE指标均显示NDP模型相比传统方法有明显优势

### 3.2 鲁棒性分析

通过向测试数据添加不同水平的高斯噪声，我们测试了模型的鲁棒性：

- 当噪声水平较低时（0.01-0.03），模型性能降低不明显
- 随着噪声水平增加（0.03-0.05），MSE和MAE都有所上升，但模型仍然能够保持基本的预测能力
- 多样本训练的模型通常比少样本训练的模型表现出更强的噪声鲁棒性

## 4. 代码使用指南

### 4.1 环境配置

确保已安装所需依赖：

```bash
pip install torch numpy pandas matplotlib scikit-learn tensorboard
```

### 4.2 实验配置

已经将相关的配置文件放置于`configs/`目录中，
其中`traffic.yaml`文件配置ndp 的`src/traffic/main.py`文件；
`traffic_baseline.yaml`文件配置`src/traffic/baseline.py`文件。
配置文件中的超参数已进行精心设置。

ndp模型大约需要训练1000个epoch，但是会面临过拟合的风险。运行方式：
```
python -m src.traffic.main
```

若需进行其他不同的实验，修改相应yaml文件即可。
注意请先完成`main.py`文件的训练，得到`ndp_best.pt`权重文件后再进行极线模型对比。
极线对比运行方式:
```
python -m src.traffic.baseline
```


### 4.3 实验结果
`main.py`文件输出于`results/5g_traffic/`目录中，其子目录为数据集名称/任务名称。
具体子项包括最佳模型权重、训练记录曲线、样本可视化、最终指标记录等。

`baseline.py`文件输出于`results/5g_traffic_baselines`，子目录命名方式同上。
具体子项包括模型在源数据集的样本可视化、迁移数据集的样本可视化；指标记录等。
