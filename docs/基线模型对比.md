# 无线智能传播模型 (WIPM) 基线模型对比实验

## 1. 概述

本文档详细记录了无线智能传播模型(WIPM)项目中各基线模型与神经扩散传播模型(Neural Diffusion Propagation, NDP)的对比实验结果。我们实现并评估了多种传统机器学习模型作为基线，并与我们提出的NDP模型进行了系统性对比，旨在全面理解各模型在无线信号强度预测任务上的性能特点。

## 2. 模型介绍

### 2.1 基线模型

在本项目中，我们实现了以下两种经典机器学习模型作为基线：

#### 2.1.1 线性回归模型 (Linear Regression)

线性回归是一种基础且直观的回归模型，它尝试通过线性组合各输入特征来预测目标值。

**数学表达式**:
$$y = \beta_0 + \beta_1 x_1 + \beta_2 x_2 + ... + \beta_n x_n + \epsilon$$

其中:
- $y$ 是预测的RSRP值
- $x_i$ 是输入特征
- $\beta_i$ 是模型参数
- $\epsilon$ 是误差项

**模型特点**:
- 简单直观，训练速度快
- 可解释性强，易于理解每个特征的影响
- 缺乏捕捉复杂非线性关系的能力
- 对于无线传播场景中的复杂地形和障碍物影响建模能力有限

#### 2.1.2 支持向量回归 (Support Vector Regression, SVR)

SVR是支持向量机(SVM)在回归问题上的应用，通过将数据映射到高维空间，寻找一个能够包含大多数样本点的最小管道。

**数学表达式**:
$$f(x) = \sum_{i=1}^{n} (\alpha_i - \alpha_i^*) K(x_i, x) + b$$

其中:
- $K(x_i, x)$ 是核函数
- $\alpha_i, \alpha_i^*$ 是拉格朗日乘子
- $b$ 是偏置项

**模型特点**:
- 通过核函数可以处理非线性关系
- 对异常值较为鲁棒
- 适用于中等规模数据集
- 参数调优复杂度较高
- 在大规模数据集上计算效率较低

### 2.2 神经扩散传播模型 (NDP)

NDP模型是本项目的核心创新，它结合了Transformer架构与扩散模型的优点，专门针对无线信号传播预测任务设计。

**模型架构**:
- 利用扩散概率模型的去噪过程，从噪声逐步恢复信号强度
- 采用双维度注意力机制(BiDimAttnBlock)处理空间和特征维度的复杂关系
- 多头自注意力机制允许模型关注不同位置和特征的交互
- 时间嵌入(TimeEmbedding)使模型能够区分扩散过程的不同阶段

**模型特点**:
- 能够捕捉复杂的非线性空间关系
- 通过扩散过程的逐步去噪提高预测稳定性
- 双维度注意力机制增强了模型对空间和特征关系的建模能力
- 相比传统模型，拥有更强的泛化能力和表达能力
- 训练过程更加复杂，需要更多计算资源

### 3.2 评估指标

我们使用两个关键指标来评估模型性能：

1. **均方根误差 (RMSE)**:
   衡量预测值与真实值之间的平均偏差，越小越好。
   $$\text{RMSE} = \sqrt{\frac{1}{n}\sum_{i=1}^{n}(y_i - \hat{y}_i)^2}$$

2. **皮尔逊相关系数 (PCRR)**:
   衡量预测值与真实值之间的线性相关性，越接近1越好。
   $$\text{PCRR} = \frac{\sum_{i=1}^{n}(y_i - \bar{y})(\hat{y}_i - \bar{\hat{y}})}{\sqrt{\sum_{i=1}^{n}(y_i - \bar{y})^2 \sum_{i=1}^{n}(\hat{y}_i - \bar{\hat{y}})^2}}$$

### 3.3 实验配置

基线模型的超参数配置如下：

**线性回归**:
- `fit_intercept`: True (是否计算截距)

**SVR**:
- `kernel`: 'rbf' (径向基函数核)
- `C`: 1.0 (正则化参数)
- `epsilon`: 0.1 (不敏感损失函数中的epsilon参数)
- `gamma`: 'scale' (核系数，'scale'表示1/(n_features * X.var()))

**NDP模型**:
- 输入维度: 24
- 隐藏层维度: 128
- 层数: 6
- 时间步数: 25
- 学习率: 0.0003
- 批量大小: 64
- 训练轮数: 120

### 4.2 可视化分析

为了更直观地理解各模型的预测性能，我们选择了`train_2304601.csv`数据集进行可视化分析，生成了三种热力图:

1. **真实值热力图**: 展示了测试场景中的实际RSRP分布
2. **预测值热力图**: 展示了模型预测的RSRP分布
3. **残差热力图**: 展示了预测误差的空间分布，帮助识别模型在哪些区域预测效果较差

通过这些可视化结果，我们可以观察到:

#### 4.2.1 线性回归模型预测结果

线性回归模型由于其简单的线性假设，在预测复杂的无线信号传播时存在明显局限性：
- 难以捕捉信号在建筑物周围的衰减变化
- 对障碍物引起的信号阴影效应表现不佳
- 在信号强度变化剧烈的边界区域误差较大

#### 4.2.2 SVR模型预测结果

SVR模型通过非线性映射提升了预测能力：
- 相比线性模型能更好地拟合非线性关系
- 在复杂地形和障碍物边缘区域的预测表现改善明显
- 计算复杂度较高，预测大规模场景时效率不高
- 在某些弱信号区域依然存在较大误差

#### 4.2.3 NDP模型预测结果

NDP模型展现了最佳的预测性能：
- 能够准确捕捉复杂环境中的信号传播模式
- 在建筑物边缘和阴影区域的预测更加准确
- 对信号衰减的空间连续性建模更为精确
- 热图中的细节保留更加完整，边界过渡更自然

### 4.3 模型优缺点分析

#### 线性回归
- **优点**: 计算效率高，训练速度快，可解释性强
- **缺点**: 表达能力有限，难以捕捉复杂的非线性空间关系

#### SVR
- **优点**: 能处理中等复杂度的非线性关系，对异常值较为鲁棒
- **缺点**: 计算复杂度较高，难以扩展到大规模数据集，参数调优困难

#### NDP
- **优点**: 建模能力强，能捕捉复杂的空间依赖关系，预测精度高
- **缺点**: 训练时间长，计算资源需求大，模型解释性较差

## 5. 总结与未来工作

### 5.1 结论

通过本次基线模型对比实验，我们得出以下结论：

1. **性能梯度**: NDP > SVR > 线性回归，这符合模型复杂度的递增趋势
2. **适用场景差异**:
   - 线性回归适用于快速原型设计和简单场景预测
   - SVR适用于中等复杂度场景且计算资源有限的情况
   - NDP适用于需要高精度预测的复杂无线环境

3. **特征重要性**: 地形、建筑物高度和距离等特征对所有模型都十分重要，但NDP能更好地捕捉它们之间的交互关系
