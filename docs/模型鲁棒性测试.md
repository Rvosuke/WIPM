# NDP模型鲁棒性测试脚本 - 测试不同噪声水平下的模型性能

1. **模型加载**：从指定路径加载预训练的 NDP 模型和配置
2. **噪声测试**：在测试数据上添加不同水平（不同标准差）的高斯噪声
3. **性能评估**：对每个噪声水平计算 RMSE 和 PCRR 指标
4. **可视化结果**：绘制噪声水平与性能指标的关系曲线，并保存为图像文件
5. **报告生成**：生成文本报告，记录不同噪声水平下的性能指标

该脚本的主要函数包括：
- `load_model()`: 加载预训练模型和配置文件
- `evaluate_with_noise()`: 在指定噪声水平下评估模型性能
- `visualize_performance_vs_noise()`: 可视化性能曲线
- `run_robustness_test()`: 运行完整的鲁棒性测试流程

您可以通过以下命令运行该脚本：

```bash
python -m src.scripts.test_noise_robustness
```
> 超参数： `--csv datasets/processed/train_2304601.csv --cfg configs/base.yaml --ckpt results/checkpoints/ndp_best.pt --save results/robustness`


默认情况下，脚本会测试七个噪声水平（0.0、0.001、0.002、0.003、0.004、0.005），但您可以通过 `--noise-levels` 参数指定自定义的噪声水平列表。例如：

```bash
python -m src.scripts.test_noise_robustness --noise-levels 0.0 0.025 0.05 0.075
```

注意，不建议将噪声水平添加到 0.1 以上，因为原始输入特征已经经过标准化处理，添加过高的噪声可能会导致输入数据的分布发生显著变化，从而使模型无法正确理解输入数据的特征。

执行后，脚本会保存两种类型的输出文件到指定目录：
1. 图像文件（`.png`）：展示噪声水平与 RMSE/PCRR 的关系曲线
2. 文本报告（`.txt`）：包含表格形式的测试结果，方便用于报告或比较

这个脚本将帮助您分析 NDP 模型在面对输入数据噪声时的鲁棒性表现，从而深入了解模型在实际应用中的可靠性。
