# 5G Traffic Dataset 使用说明

## 1. 数据集简介

本数据集包含5G网络流量的多种时间序列数据，适用于网络流量预测、时序建模等任务。数据来源于真实5G基站，覆盖多个小区与波束，采样频率为1小时。

### 数据类型与文件

- **Number类数据**（数值型指标）：
  - `number_value_cell_2_beam_19.csv`：小区2波束19
  - `number_value_cell_2_beam_27.csv`：小区2波束27

- **Throughput (thp)类数据**（吞吐量指标）：
  - `thp_value_cell_0_beam_1.csv`：小区0波束1
  - `thp_value_cell_2_beam_0.csv`：小区2波束0

每个CSV文件均为独立的预测任务。

### 数据格式说明

每个CSV文件包含如下字段：

| 列名         | 含义                         | 示例                |
|--------------|------------------------------|---------------------|
| date         | 时间戳（yyyy/MM/dd HH:mm）    | 2022/01/01 12:00    |
| value        | 原始数值（number/thp）        | 61300.0             |
| ma_value     | 滑动窗口均值（窗口=5）        | 0.0 或 61.5         |
| lg_ma_value  | ma_value的以10为底对数        | 7.89 或 2.45        |

- **时间跨度**：每个文件覆盖多个连续天，每天24条记录。
- **缺失值处理**：所有缺失值均用0填充。

## 2. 任务目标

本数据集主要用于**时间序列预测**，即根据历史流量数据预测未来流量。每个CSV文件为一个独立的预测任务。

### 任务划分

- **多样本训练**：训练集:测试集 = 8:2（80%训练，20%测试）
- **少样本训练**：训练集:测试集 = 2:8（20%训练，80%测试）

### 预测场景

- **长期预测**：输入连续12小时（12行）数据，预测未来24小时（24行）数据。
- **短期预测**：输入连续12小时（12行）数据，预测未来6小时（6行）数据。

## 3. 实验设计与复现步骤

### 输入输出格式

- **输入特征**：选用`value`、`ma_value`、`lg_ma_value`。
- **输入长度**：12小时（12行）
- **输出目标**：根据预测场景来确定，例如长期预测是未来24小时（24行）的`value`列

### 实验流程

1. **选择数据文件**，按上述比例划分训练集和测试集。
2. **构造样本**：滑动窗口方式提取输入序列和对应的输出序列。并进行特征归一化（z-score）
3. **模型训练**：选用NDP模型。
4. **模型评估**：每隔固定的epoch在测试集上评估预测性能（如MSE、MAE）。
5. **结果可视化**：绘制预测值与真实值的对比图，观察模型性能。
6. **泛化性能评估**： 尝试在测试数据的输入序列加入不同水平的高斯噪声，
   观察模型的鲁棒性。
7. **模型保存**：保存训练好的模型参数，以便后续使用。
